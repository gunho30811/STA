## 헤더 튐·흰 바탕·로고 일관성

### ① 페이지 넘길 때 헤더가 위로 튀던 현상 — 원인 규명

측정해보니 React 뷰어(`/profit/`·`/samsam/`·`/gangnam/`·채팅)에서 네비가
**로드 직후 top=8px → 350ms 후 top=0px** 로 이동하고 있었다.

원인: 그 페이지들은 앱 CSS(`assets/*.css`)가 늦게 붙는데, 그 전까지 **브라우저 기본
`body{margin:8px}`** 가 남아 sticky 네비가 8px 아래에서 시작한다. CSS가 로드되면
`body{margin:0}`이 적용되며 위로 튀어 오른다.

→ 주입 네비의 `<style>` 맨 앞에 `body{margin:0}`을 넣어 해결(네비와 함께 즉시 적용된다).
재측정 결과 모든 페이지에서 0ms부터 top=0.

### ② 흰 바탕

- 계산기: `--bg` `#EEF1F6` → `#FFFFFF`
- React 뷰어 4종: `body` 배경 `#f3f5f7` → `#ffffff` (탭 활성 배경 등 다른 용도의 같은 색은 유지)
- 지도(`/map`)는 다크 UI라 그대로 뒀다(지도 캔버스 뒤 배경).

### ③ 로고 일관성

감사해보니 로그인 상태는 이미 일관됐지만(모든 페이지 x=24, y중심 28, 20px), 그 외가 제각각이었다.

- 랜딩 **푸터 로고 21px** → 20px (헤더와 동일 규격)
- 로그인·가입 페이지 로고: 인라인 스타일(`color:#171A23`)에 자간·굵기 규칙 없음
  → `.brandmark` 클래스로 헤더와 같은 규격(잉크 `#101B2D` + `dit` 브랜드색, 자간 -.025em)
- `← rendit 홈` 링크도 같은 색 규칙 적용
- **React 뷰어 파비콘이 아직 옛 퍼플**이었다(`frontend/index.html`이 별도 파일이라 누락).
  web과 같은 마크로 교체 후 dist 재빌드.
