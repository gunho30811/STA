### 3. 외부 데이터 연계 — 수요 근거 (#208~#214, #217, #219)

"삼삼 매물이 없는 동네는 예약률이 없어 수요를 알 수 없다 → 왜 수요가 있는지 외부 증거가 필요"라는
논의에서 출발. 수요 유형별 증거물품을 단계적으로 붙임.

- **Phase 1 미개척 지역**(#208): 외부 API 없이 네이버 `confirmYmd`로 동별 월세 회전율(최근7일 신규/
  활성재고) 계산 → 삼삼 예약률 없어도 수요 신호. 회전율↑ & 삼삼 2개↓ 동을 대시보드 '🎯 미개척 지역'에.
- **Phase 2 수요시설 POI**(#209, #211, #213, #214): `data/poi.csv`+`common/poi.py`(subway 패턴).
  🏥병원·🎓대학·🏭산단·📚학원가·🚄교통·🗼관광. 처음 수동 86곳 → 학원/교통 111 → 관광 236 →
  개별 관광지 1,502곳(tourspot, 지도 줌15+에서만) = **총 1,748곳**. 지도 레이어(줌12+) + 스팟 카드 근거
  ("🏭판교테크노밸리 1.4km" 등).
- **Phase 3 진입 원가**(#210): 동별 주거 소형(전용20~60㎡·월세20~200) 월세·보증금 중앙값 → 스팟 카드
  "진입 월세 127만/보증금 1000만" + 카드 클릭 시 계산기에 시세 자동입력. 🐛 percentile_cont 2회 SELECT
  시 컬럼명 충돌로 월세가 보증금 값에 덮어써지던 버그 → 별칭+인덱스 접근.
- **병원 자동수집**(#212): data.go.kr 심평원 API. 403은 활용신청 반영 지연이었고, **Encoding 키를 URL에
  그대로**(Decoding/params= 는 '/'·'+' 재인코딩으로 401) 붙이니 200 OK. 수도권 병원 151곳 자동수집
  (`pipeline/fetch_poi_hospital.py`). 관광은 TourAPI(`fetch_poi_tour.py`).
- **SGIS 종사자수**(#214 수집기, #217 반영): `pipeline/fetch_sgis_workers.py` — sgisapi 인증 →
  stats/company.json 행정동별 종사자수(UTM-K→WGS84 변환). 수도권 1,183동(여의동 19.5만·가산동 18.2만).
  🐛 행정동↔법정동 이름 불일치(역삼1동 vs 역삼동, 수원 구천동=행궁동) → **좌표 기반 조회**(workers_near,
  1.2km 합산, 격자 인덱스)로 회피. 추천 점수에 종사자 보너스(최대 4점).
- **소비력 지표**(#219): SGIS에 소득 API 없어 우리 DB 아파트 보증금 중앙값으로 근사(대치10억·반포9억
