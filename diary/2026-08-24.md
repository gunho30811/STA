## 헤더·로고에 명암(elevation) 부여 + "AI가 만든 티" 안 나게 하는 CSS 규칙 조사

"로고랑 헤더에 명암이 없어서 촌스럽다"는 지적. 자료를 찾아보고 규칙을 적용했다.

### 조사 결과 (요약)

- **AI 슬롭 판별 신호**(avoid-ai-design, Hallmark 등): Inter 기본폰트, **보라→파랑 그라데이션**,
  `rounded-2xl shadow-lg` 남발, backdrop-blur 반사적 사용, 아이콘-둥근사각형, 가운데 정렬 히어로
  + 3카드 그리드, 균일한 `gap-4/p-6`(공간 위계 없음), Lucide `Sparkles/ArrowRight`, 이모지 불릿.
  원인은 "결정을 안 한 것" — 모델이 학습 데이터의 평균값(=Tailwind indigo-500)으로 수렴한다.
- **그림자가 싸구려로 보이는 이유**(Josh Comeau): ① 검정(hsl 0 0% 0%) 단일 레이어 ② 요소마다
  광원 방향이 제각각 ③ 거리에 따른 흐림·감쇠 무시. 해법은 **광원 하나 고정 + 배경 색조에 맞춘
  hue의 그림자를 여러 겹**, 고도가 올라갈수록 offset↑ blur↑ alpha↓.

### 적용

- **그림자 규칙**: 검정 대신 `hsl(248deg 45% 35%)`(브랜드 계열)를 alpha .04로 4겹.
  광원은 위쪽 한 곳으로 통일(offset x=0).
- **스크롤 반응 헤더**: 맨 위에선 그림자 없이 hairline만, 4px 이상 스크롤되면 hairline을 지우고
  그림자를 켠다(본문이 헤더 밑으로 들어갈 때만 떠 보이게). 로그인/비로그인 헤더 모두.
- **로고**: 워드마크만 있어 평평했다 → 10px 마름모 마크 추가. 같은 색 계열의 밝은 면/어두운 면
  (`linear-gradient(145deg,#6B52F5,#3A1FC9)`) + inset 하이라이트 + 미세 드롭섀도로 입체감.
  워드마크는 `#1B1B3A` → `#0F0F23`로 대비를 올리고 자간을 -.025em로 조였다.
- **대비**: 메뉴 텍스트 `#5A5A7A` → `#45456B`, 활성 pill에 inset 하이라이트,
  회원가입 버튼을 외곽선 → **채운 브랜드색**(화면에서 눌러야 할 단 하나의 액션이라
  reference-rules 규칙4의 예외에 해당).

주의: 우리 브랜드색이 보라(#4D2EE9)라 AI 슬롭 신호 1번과 겹친다. 다만 그라데이션 배경으로
쓰지 않고 포인트로만(면적 1~3%) 쓰는 한 문제가 아니다 — 이번 작업에서도 그라데이션은 10px
로고 마크에만, 그것도 같은 색조 안에서만 썼다.

참고: https://github.com/funboy322/avoid-ai-design ·

## 브랜드색 교체: 퍼플 → 딥 잉크 네이비 (#123A6D)

사용자 확인 결과 **퍼플은 사용자가 정한 색이 아니었다**. 이력을 보면 07-14 리브랜딩 커밋
(#163, Claude 세션)에서 "로고 퍼플"로 `#4321F3`이 들어왔고, 07-22 랜딩 리디자인(#263)에서
`#4D2EE9`가 추가돼 **미묘하게 다른 보라 2종이 공존**하던 상태였다. 팔레트를 확정한 적이 없다.
게다가 인디고/퍼플은 AI 기본값과 겹쳐(어제 조사) "결정한 색"으로 읽히지 않는다.

- 방향: **신뢰감 계열**(사용자 지시) → `#123A6D` 딥 잉크 네이비.
  - 흰 배경 대비 **11.34:1**(기존 퍼플 7.28), 흰 글자 대비도 동일 — 텍스트·버튼 양쪽 사용 가능.
  - 순수익 초록(#148A5E)·손실 빨강(#D24545)·골드(#D89700)와 색상환에서 충분히 떨어져 있다.
  - Tailwind 기본값(blue-600/indigo-500)을 피한 값 — 기본 팔레트 색이면 다시 "평균값"이 된다.
- 파생: hover `#0D2B52`, 로고 마크 밝은 면 `#2C5A9E`, 어두운 배경 강조 `#7FA6DC`,
  틴트 `#E9EEF7`/`#E4EBF6`, 그림자 hue `hsl(214deg 72% 25%)`.
- 보라 기 도는 중성색도 쿨 슬레이트로: 본문 `#1B1B3A`→`#16233A`, 보조 `#8080A8`→`#6B7A90`,
  선 `#E2E2F0`→`#E3E8EF`, 페이지 배경 `#E7E9F3`→`#EEF1F6`.
- 범위: web 3파일 + frontend/src 12파일 **총 128곳** + rgba 표기 3곳. 프론트엔드 dist 재빌드.
  남은 퍼플 흔적 0.
