## 계산기(/calc) 라이트 테마 리디자인

- 사용자가 디자인 토큰(브랜드 #4D2EE9·hover #3A1FC9·틴트 #ECEAF8, 수익 녹색 #148A5E,
  손실 빨강 #D24545, 배경 #F7F6F3→이후 #F4F6FB로 조정, 다크 앵커 #181430, 골드 #D89700)을
  먼저 정의 → 계산기 페이지(`design/rendit-calculator-design.png` 시안) 리디자인에 적용.
- 계산 수식·비즈니스 로직은 전혀 안 건드리고 표시(마크업/CSS/포맷)만 변경 — 여러 커밋으로
  쪼개서 진행(머지 편의):
  1. 입력 존: 다크→라이트 전환, "내가 내는 돈" 카드를 핵심 3개(월임차료·보증금·월관리비) +
     `<details>`로 접는 세부비용 4개로 분리, "받는 돈" 카드에 공실률 슬라이더(0~30%, 기본10%) 추가.
  2. 결과 존: 기존엔 표 안에만 있던 "월 순수익"을 슬라이더가 고른 공실률 기준으로 히어로
     지표로 승격, KPI 3개(영업이익률·손익분기·주순익)로 재배치. 손익분기는 기존 "손익주"
     값을 ×7 해서 "월 약 N일" + 괄호로 공실률 병기(표시 단위 변환만, be 값 자체는 불변).
     원시 계산값(주매출·주임대원가·연임차원가·손익분기 예약주수)은 "계산 내역"으로 접기.
  3. 공실률 시나리오 표: "연매출" 열을 "월 예약(환산)"(30일×(1-공실률))로 교체, 손익분기
     지점에 골드 점선 구분행 삽입, 연/월 순수익은 ₩ 대신 부호(+/-) 표시로 흑자/적자 색 구분.
     표 위 경고 배너 + 표 아래 "★ 공급부족 스팟 보기" CTA(→ /auth/signup, 랜딩과 동일) 추가.
  4~6. 폴리시: 계산내역 섹션을 흰 카드로 감싸기, 섹션 간 세로 여백 최소 20px로 확장,
     히어로 카드 테두리 제거(그림자만), 배경 흰색→#F4F6FB로 조정, 히어로/표 강조색을
     초록→브랜드색으로 변경(주 순익 KPI는 초록 유지 — CSS 특정도 충돌로 무채색 되던 버그도
     같이 수정), 안 쓰는 구 CSS(.row/.out/.kpi/.big) 정리.
- **로그인 상태별 헤더 분기**: `/calc`에 비로그인 시에만 랜딩과 동일한 헤더(rendit+로그인/
  회원가입)를 표시하도록 Jinja 조건 추가. 로그인 상태에서는 이미 있던
  `auth.py`의 `_inject_nav`(after_request 훅)가 통합 네비바(수익성·렌트분석·지도·계산기·
  부동산매물·통합채팅·로그아웃)를 자동 주입하므로 그걸 그대로 활용 — 새로 만들 필요 없었음.
  실제 비밀번호 없이 앱 SECRET_KEY로 서명한 테스트 세션 쿠키로 두 상태 다 검증.
