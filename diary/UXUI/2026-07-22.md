## 랜딩페이지 리디자인 (rendit-landing.html 참고)

- 사용자가 올려준 frontend/design/rendit-landing.html(디자인 참고용, no-code 빌더 산출물)을
  바탕으로 web/portal.py의 공개 랜딩(PUBLIC_LANDING)을 다시 작성. 실제 서비스 스택은
  Next.js가 아니라 Flask+Jinja 인라인 HTML이라, 새 뷰어를 만드는 대신 기존 구조를 유지하며
  디자인만 갈아엎음(배포 변경 없음).
- 섹션 순서: 헤더 → 히어로 → 문제 3박스 → 서비스 3종 → 실시간 계산기 → 공급부족 스팟
  (블러 잠금 미리보기) → 신뢰 → 회원가입 CTA.
- 브랜드 컬러 #4D2EE9는 신규 랜딩 전용 요소(버튼·아이콘 타일)에만 적용 — 로그인 후
  대시보드(LANDING)의 기존 아이콘 색(#4321F3)은 건드리지 않음.
- 계산기: 월순수익=(주임대료×예약률×52 − 월임차료×12)÷12, 영업이익률·월세대비 배수·매물수
  까지 슬라이더 3개로 클라이언트 실시간 계산(vanilla JS). 무료 도구(계산기·지도)를 히어로
  1순위 CTA로, 회원가입은 2순위(텍스트 링크)로 배치.
- "최신 갱신일"은 실제 latest_listing_churn() 크롤일자를 반영.
- 헤드리스 크롬으로 데스크톱/모바일 렌더 확인 + 로컬 python web/portal.py 로 실사용 검증
  (자동 reloader라 수정 즉시 반영 확인).
- 사용자 피드백 반영: 헤더 nav(계산기/지도/데이터근거) 링크 제거, 히어로 두 버튼(계산기·지도)
  위계 통일(둘 다 btn-primary), 버튼 보라 그림자 범위 축소, "또는 회원가입" 위 여백 조정.
