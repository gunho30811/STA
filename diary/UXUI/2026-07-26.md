## 랜딩페이지 CTA 동선 정리 + signup-card 리스타일

- **CTA를 실제 목적지로 직결**: 히어로 "무료 계산기 써보기"(#calc 스크롤 → `/calc`), 서비스 카드
  "지금 계산하기"(#calc → `/calc`), 무료계산기 nudge 배너 "추천 스팟 보기"·wall-card "가입하고
  전체 열기"·signup-row "또는 회원가입"(전부 #signup 스크롤 → `/auth/signup` 직행)으로 변경.
  페이지 내 스크롤 앵커 대신 실제 회원가입 전 사용 가능한 계산기 페이지·이메일 가입 페이지로
  바로 이동하게 함.
- **signup-card 리스타일**: 배경 `#181430`(어두운 네이비), 서브텍스트 `#A9A4C9`, 버튼은
  `#4D2EE9` 배경+흰 글씨 → hover 시 배경/글자색 반전. `letter-spacing` 제거, 승인절차 안내
  `p.fine` 문구 삭제(불필요한 CSS도 함께 정리).
- 히어로 배지(`span.tag` "단기임대용 매물 찾기") 삭제.
- trust 섹션에서 "네이버" 단어 삭제(카드 2곳). `trust-note`는 "최신 갱신일: {날짜}" 로직을
  걷어내고 "출처: 부동산 매물 및 단기임대 예약 데이터 기준"으로 단순화 — DB의 `samsam_churn`
  테이블이 실제로 0건이라 항상 "-"만 뜨던 상태였음(크롤 파이프라인 쪽 이슈로 별도 확인 필요,
  랜딩 자체는 문제 없었음). 더는 안 쓰는 `churn` DB 조회도 `home()` 비로그인 분기에서 제거.
- 로컬에서 카카오맵 지도(`/map`)가 안 뜨는 문제 확인: `.env`에 `KAKAO_MAP_CLIENT_ID` 자체가
  없어서였음 → 실제 키를 받아 넣었으나 여전히 `kakao is not defined`로 안 뜸(SDK 스크립트는
  200으로 정상 응답하지만 실행 시 막힘 — 카카오 콘솔의 플랫폼 허용 도메인에 `localhost:8000`/
  `127.0.0.1:8000`이 등록 안 됐을 가능성). 배포 서버에서는 정상 확인돼서 로컬 이슈는 보류.
