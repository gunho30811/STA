# 2026-07-03

## 건물 인기 탭 — 오피스텔(건물명) 검색 + 자체 검색 색인 모듈 (feature/building-name-search)

건물 인기 탭에 건물명(오피스텔 명) 검색을 추가하면서, 검색 로직을 별도 `search/` 패키지로 분리.

- **엔진 선택**: Elasticsearch 검토했으나 제외 — 우리 배포가 Vercel 서버리스(상주 서버 없음,
  읽기전용 FS)라 ES는 외부 클러스터(월과금)가 필요하고, 데이터가 적어(수만 건) 가치 대비 과함.
  SQLite FTS5(trigram)도 검토했으나 **trigram 토크나이저가 3자 미만 질의를 못 잡음**("강남"·
  "한화" 같은 2자 한글 검색이 빈 결과) → 실측 확인 후 탈락.
- **결정**: 외부 엔진 없이 **순수 파이썬 n-gram(기본 2-gram) 역색인**을 직접 구현(`search/`).
  2자 한글 검색이 바로 되고, JVM·외부서버·trigram 제약 전부 없이 Vercel에서 그대로 동작.
  - `search/text_index.py` `TextIndex`: normalize(공백제거+소문자) → n-gram posting →
    질의도 n-gram으로 쪼개 교집합으로 후보 좁히고 substring 재확인으로 오탐 제거.
- **연동**(`web/samsam_app.py`): 데이터가 프로세스당 1회 로드(`_LC`)되므로 색인도 최초 사용 때
  1회 구축(`_indexes()`, 건물명·역명). `/api/buildings`의 건물명 검색(신규)·역 검색(기존)을
  모두 이 색인으로 태움. 실측: 색인 결과가 기존 순진 substring과 100% 동일(건물명 5203·역명 466).
- **프론트**(`templates/samsam.html`): 건물 인기 탭에 "건물명 검색" 입력 추가(역 검색 옆).
- 앞으로 텍스트 검색은 전부 `search/`를 거치게 확장 예정.
