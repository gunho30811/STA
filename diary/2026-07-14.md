## 카카오 로그인 KOE101 원인 = 재배포 누락 + 카카오 회원도 관리자 승인 게이트 (fix/kakao-admin-approval)

- **KOE101 진단**: 프로덕션 `/auth/kakao`가 카카오로 보내는 URL의 `client_id=`가 비어 있던 것이 원인
  (redirect_uri는 정상이었음). Vercel 환경변수에 `KAKAO_CLIENT_ID`는 저장돼 있었으나 **저장 후
  재배포를 안 해** 예전 배포(빈 값)가 떠 있었음. 빈 커밋 push로 재배포 → `client_id` 채워짐 확인, KOE101 해소.
  (로컬 `.env`엔 카카오 키가 없어 로컬 서버는 여전히 카카오 미동작 — 필요 시 별도 주입.)
- **승인 게이트 누락 수정**: 신규 카카오 회원이 `approved=TRUE`로 자동 생성 + 즉시 세션 로그인돼,
  이메일 가입(관리자 승인 대기)과 정책이 어긋났음. `kakao_callback`을 수정:
  - 신규 INSERT를 `approved=FALSE`로(카카오 인증은 email_verified만 대체, 관리자 승인은 필요).
  - 세션 부여 전 `role/approved` 확인 — 미승인 일반 회원은 로그인 대신 '가입 완료·관리자 승인 후
    로그인' 안내 페이지 반환(이메일 가입과 동일 UX). admin/이미 승인된 회원만 로그인.
  - 기존에 이미 approved=TRUE로 만들어진 카카오 회원은 그대로 로그인 유지(신규만 게이트).
- 검증: mock으로 3경로(신규 가입=승인대기·세션없음 / 승인된 회원=로그인 302 / 미승인 재시도=대기) 통과.
