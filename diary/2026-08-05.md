# 2026-08-05

## 크롤 대상 지역 확장: 부산·천안 (+ 수도권 필터 버그 2건)

사용자 요청으로 삼삼·네이버 크롤에 **부산 전역과 천안시**를 추가했다. 지역 조건이 코드
여러 곳에 하드코딩돼 있어(수도권 시도명 3개) 먼저 한 곳으로 모았다.

- **`common/target_regions.py` 신설** — 크롤·노출 대상 지역의 단일 출처.
  `METRO_PREFIX`(서울/경기/인천 접두) + `EXTRA_REGIONS`(기본 `부산,천안시`,
  env `RENDIT_EXTRA_REGIONS`로 조정). `in_target()` / `sql_where()` /
  `sql_literal()`(뷰 정의용) / `short()` 제공.
  - 접두·부분일치를 쓰는 이유: **시도 표기가 소스마다 다르다.** 삼삼은 `부산광역시`,
    네이버는 `부산시`. 천안은 시도가 아니라 시군구라 `'시도 시군구'` 문자열 부분일치.

### 이번에 드러난 기존 버그 2건 (같은 표기 불일치가 원인)

1. **네이버 일일 크롤이 사실상 경기도만 돌고 있었음.** `gen_naver_dongs.py`가
   `samsam_snapshots`를 `('서울시','경기도','인천시')`로 조회하는데 실제 값은
   `서울특별시`/`인천광역시` → 대상 동 목록에 **경기도 동만** 들어갔다(서울·인천은 동명이
   겹칠 때만 우연히 포함). 08-05 크롤 실적이 그 증거: 131,272건 중 경기 121,649 /
   서울 7,747 / 인천 1,876.
2. **공급부족 스팟 추천 40곳이 전부 경기.** `samsam_app`·`portal`이 네이버 `listings`를
   삼삼 표기(`서울특별시`…)로 필터 → 경기도만 매칭(448,008 / 전체 769,476).

둘 다 `target_regions`로 교체해 수정. 부수적으로 이 수정만으로 서울·인천 커버리지가
정상화되므로 다음 네이버 크롤부터 대상 동 수가 크게 는다.
