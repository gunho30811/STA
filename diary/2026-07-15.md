### 4. 로컬 크롤 GUI (.exe) — gui/rendit_crawler.py + common/local_db.py
- 사용자 요청: 버튼 누르면 창 뜨고 크롤하는 프로그램. 접속정보는 입력창에 기입. DB 대신 로컬 폴더 누적도 선택.
- tkinter GUI: 삼삼 계정 2개·매물종류 체크박스·테스트(50건)·실시간 로그. 입력값은 옆
  `rendit_crawler_config.json`에 저장. 파이프라인(crawler→snapshot→export)을 in-process 호출.
- **저장 위치 선택**:
  - Supabase(DB URL) 또는 **로컬 폴더(SQLite)**. 로컬은 `common/local_db.py`를 `sys.modules['db']`로
    주입해 크롤러가 그대로 선택 폴더의 `samsam.db`에 upsert 누적 + jsonl도 그 폴더에 export.
  - local_db는 samsam 크롤러의 PG 방언을 SQLite로 흡수: `%s`→`?`, `ON CONFLICT ... EXCLUDED`(SQLite 지원),
    `ALTER ... ADD COLUMN IF NOT EXISTS`(중복 무시), 행은 `r[0]`/`r['col']`/`r.get()` 모두 지원.
  - 오프라인 단위검증 통과: init→ALTER→upsert(%s+ON CONFLICT)→SELECT→snapshot→export, 폴더에 db+jsonl 생성.
- PyInstaller onefile+windowed 빌드(~60MB). 크로미움은 번들 안 하고 PC 설치본 사용(다른 PC는 첫 실행 시
  `playwright install chromium`). 프로즌 exe에서 `--selftest`(모듈/경로/의존성) PASS.
  ※ 실제 [크롤 시작] 클릭(크롬 로그인) 런타임은 GUI라 미검증 — 로컬 크롤과 동일 코드경로.
- 배포물은 bytes 커서 채팅 첨부 불가 → 바탕화면 `삼삼크롤러.exe`로 전달.
