## 카카오 연동 (로그인 + 지도)

### 카카오 로그인 복구 (KOE101 해결)
- 원인: 카카오 키가 Vercel 환경변수에만 있고 서버 .env에 없음(빈 client_id) + 새 도메인 미등록.
- 사용자가 새 카카오 앱(Redndit) 생성·도메인/Redirect URI 등록 → REST API 키를 서버 .env
  (KAKAO_CLIENT_ID, KAKAO_REDIRECT_URI)에 설정, 웹 재시작.
- 검증: /auth/kakao → kauth.kakao.com 인가 URL이 KOE 에러 없이 카카오 로그인 페이지 정상 렌더.

### 지도 카카오맵 전환 (map_view v6)
- Leaflet/OSM → Kakao Maps JS SDK. 지도 기능이 활성화된 별도 앱의 JavaScript 키 사용
  (.env KAKAO_JS_KEY, portal이 템플릿에 주입 — 키는 레포에 안 넣음).
- 줌 변환 z=20-level 로 기존 티어 로직(시군구≤13/동14/핀15+) 그대로 재사용.
- 마커류 전부 CustomOverlay(앵커0,0+CSS transform), 행정동 폴리곤은 kakao.maps.Polygon
  1,183개 + 뷰포트 컬링(idle마다 setMap on/off), 추천 스팟 Circle, diff 렌더 유지.
- 네이티브 키는 웹에선 불필요(모바일 네이티브 앱용)라 미사용.

### 지도 색칠 개편 — "맵이 징그럽다" 피드백 (#237)
- 전 동을 신호등 3색으로 칠하니 서울 전체가 분홍 얼룩(대부분 동이 예약률<30 빨강) →
  **수요 높은 동만 브랜드 보라 3단계(70/55/40%)로 강조**, 낮음·표본<3은 거의 투명.
- 카카오맵 배경이 그대로 살아나고 뜨거운 동네만 눈에 들어옴 — 공급부족 스팟 파인더 목적에 부합.

### 추천 스팟 v2 — 매물 단위 수익 추천 (사용자 요청)
- **100점 만점**: 후보 동 최고점=100으로 정규화(score100), 뱃지 "n점/100".
- **매물별 예상 월순익(enet)**: 같은 시군구·유형 삼삼 주당가 중앙값 × 4.345주 × 예약률 중앙값
  − (월세+관리비). 추천 동은 삼삼 매물이 없는 곳이라(그게 추천 이유) 시군구 비교군으로 근사,
  표본<5면 수도권 유형 중앙값 폴백 (_sam_comps/_est_net).
- **필터 기본값**: 예상 월순익 ≥50만 · 보증금 ≤1000만 — 지도 상단 입력(예상순익≥/보증금≤)으로
  사용자가 조정 가능(min_profit/max_dep 파라미터). 매물은 예상 순익 높은 순 정렬·표시.
- **동 폴리곤 강조**: 추천 스팟 원 대신 실제 행정동 경계를 노랗게 칠함(좌표 판정, 경계 없으면 원 폴백).
- 매물 카드에 유형·관리비·예상 월순익(+n만) 표기. 매물 있는 동 우선 정렬.

### 카카오 로그인 완성 + 가입 승인 UX (#240)
- 새 카카오 콘솔은 Redirect URI 위치가 [앱 > 플랫폼 키 > REST API 키 카드] 안으로 이동
  (구 [카카오 로그인] 메뉴에 없음 — 데브톡에도 혼란 다수). 등록 후 실로그인 성공.
- 가입 승인 UX: 신규 가입 = "가입 완료 — 관리자가 승인해야 로그인이 완료됩니다" /
  미승인 재방문 = "⏳ 승인 대기 중" 페이지로 구분.
- 신규 가입(카카오·이메일) 시 관리자에게 승인 대기 메일 자동 발송(notify_admin_signup,
  백그라운드 스레드·실패해도 가입 흐름 무영향). 수신자 ADMIN_NOTIFY_EMAIL(기본 SMTP_USER).
